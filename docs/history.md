# 历史列表与阅读状态

历史按本地日期分组，正文可选择。每行在悬停、键盘聚焦或展开时显示复制、播放和更多操作；触摸环境始终显示操作。展开、播放、版本、重识别与删除都在对应记录内完成。识别文字只读。

## 数据契约

`HistoryPort.browse(search, cursor?, pageSize?)` / `reread(search, ids)` 调用主窗口专用 `history_browse`，返回 `records / total / nextCursor`。旧 `list` 保持兼容，完整文字和所有识别尝试由 `detail` 按需读取。

页面每页最多20条；browse省略pageSize时仍为50，上限50。指定ID复读每次最多20条，共用摘要选择逻辑。摘要含记录身份、版本、创建时间、时长、当前展示尝试、最多240个 Unicode 字符的预览、截断标记、最新尝试状态/错误、音频状态及旧版本匹配标记；没有文件路径、凭据或完整识别版本数组。复制先读取绑定尝试的完整文字，系统剪贴板写入成功后才显示反馈。已失效的复制读取返回取消结果，不写入剪贴板，也不显示成功。

按 `(created_at DESC, id ASC)` 翻页，复用 `speech_records_recent` 索引。游标携带最后一条的排序位置，删除该记录后仍可继续。数量与当前批摘要在同一读事务中取得。排序稳定，但多批读取不是整个数据库的冻结快照；新记录通过刷新通知进入列表。已访问页保留原ID及起止游标，删除不补位，不显示动态总页数。

搜索去除首尾空白，使用既有 NFC/无区域小写/NFC 归一化和参数化 `instr`；百分号、下划线作为普通文字。搜索覆盖全部尝试，当前版本匹配时优先展示，否则展示最新匹配版本并标记“匹配旧版本”。展开与复制绑定摘要中的尝试ID。普通索引不加速任意包含搜索；性能检查见 [testing.md](testing.md)。

本修订没有数据库迁移，沿用原有成功结果、版本、音频占用保护、删除意图和恢复流程。

## 前端职责与缓存

应用层创建 `HistoryFeedStore`，在主窗口前端存续期间保留搜索、已加载摘要、展开记录ID和阅读位置。完整详情只存在于当前展开行，收起释放。历史模块通过端口读取数据，不导入模型或词典模块内部实现。

搜索180ms防抖，重新建立第一页。翻页、搜索、刷新绑定阅读代次，旧响应不覆盖新页。翻页保留当前内容，失败保留原页与重试目标；其间后台更新合并到收尾复核。复制与展开也检查页代次；翻页先等待现有播放命令链停止，失败保留原页并明确反馈。

页面重进及隐藏恢复保留当前页、展开项和位置，再按原ID复读。新记录只显示“有新记录，查看最新”，主动刷新回第一页重新分页。完整摘要最多缓存3页，轻量ID/游标书签保留到搜索或主动刷新。删除、搜索匹配变化只移除原页记录，不跨页补位；删空页优先退回上一非空页，向前导航越过空书签，没有前页时向后寻找。原始末尾游标不会随删除改变。总数以查询为准，重复删除通知不重复减数。首页用量继续在实际存档及删除完成后刷新。

保存设置采用显式保存；未保存修改在离开页面或打开其他设置前受保护。保存时重新读取偏好，保留其他入口修改的麦克风；历史/音频/期限发生冲突时要求重新确认。云端识别仍会向选定服务发送音频，历史保存在本机不等于供应商零保留。

## 操作生命周期

同一时间只展开一条。切换展开记录或离开页面时停止原回放。播放命令按端口串行排序，离开期间未完成的播放会先完成再停止，后续挂载的播放不能被旧清理覆盖。

只有正在播放且页面可见时，以250ms间隔查询原生进度；一次查询结束后才安排下一次。暂停、停止、结束、隐藏和卸载清理计时器；恢复时查询一次再决定是否轮询。命令和查询分别检查操作代次，旧状态不能覆盖新的暂停、定位或播放。播放时长与进度以原生接口为准。

成功重识别切换当前结果；失败或取消保留原成功正文，最新尝试单独反馈。版本菜单可以查看所有既有结果。音频到期、未采集、缺失和损坏分别表达。没有可用音频时不能播放或重识别。用户确认重识别才发请求；删除确认明确包含文字、所有版本和录音，清理失败保留重试入口。

悬浮窗无历史权限。录音、播放、保存恢复规则及供应商边界见 [speech.md](speech.md)。

## 普通归档恢复

历史创建、检查点、处理单元和终态通过原生归档所有者保存，不阻断已经确认有效配置与目标的口述。短暂写锁采用有限重试；普通恢复事实位于当前用户数据的 archive-recovery，采用版本化格式、原子替换和持久写入。重放只补本地存储，不重新识别、生成或向目标输入。确认数据库结果后移除相应恢复事实；相同身份不同内容保留冲突。

取消意图先于普通正文重放；缺少父项的取消资料保留，等待父项恢复，不将无对应数据的意图当作全库不可用。删除先提交 delete_pending，再使磁盘与进程内对应恢复事实失效，实际删除前再次检查。取消后的录音不得被旧 ready 事实重新启用。历史偏好沿用任务已确认的快照，不新增历史容量配额。数据库与恢复文件都不能写时保留有界进程内事实；不能保证进程退出后的持久性。

归档事件兼容旧字段，增加可选 attemptId、revision、state。原生汇总识别、录音、处理及投递的实际结果；前端按任务和尝试拒绝迟到修订。首页没有全局存档警告，已保存仅表达数据库确认。历史正文与分页分别占用列表滚动区和独立底部区域。
