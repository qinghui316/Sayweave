# API 模型配置与后端基础

## 本地流式识别

Nemotron 3.5 ASR Streaming 0.6B Q4已随0.1.19交付，模型质量、设备性能、受控宿主与真实麦克风证据保持各自来源和限制；既有Tab／微信旧块接管及完整跨软件学习验收仍独立记录。

语音设置中的本地卡管理下载、校验、取消、重试、选择和删除。下载不会改变默认模型；点击卡片才变更现有语音默认。“⋯”菜单提供计算方式和删除。计算方式默认自动选择可用设备，没有可用 GPU 时使用 CPU，也可选择“仅 CPU”。文字处理仍独立选择当前云端模型；启用整理时文字会按该配置发送。

本地配置使用 `assetId/engine/device`，没有云端 URL 或凭据。ModelAssets 只管理文件与占用；LocalAsrRuntime 管理按需启动的计算子进程；识别适配器输出既有 RecognitionSession 事件。Session、Draft 和原生输入不按模型名称分支。只有模型和真实流、麦克风均就绪才发布录音状态，冷加载不提前展开。

首版不提供 Nemotron 原生 ASR 热词注入。已有词典、自动词条和表达偏好继续按原入口用于文字整理，不强制替换原始识别文字。CPU/GPU、受控音频、目标软件正文和真实麦克风分别记录结果。

资产 ID 绑定不可变的文件版本、大小和 SHA256；权重或量化版本改变时新增 ID，不覆盖旧身份。同一引擎增加模型只扩展资产定义和 `models/local.rs` 的识别参数映射；不同引擎增加相同事件契约的运行时适配；未来本地 LLM 复用资产服务，进入文字处理接口。GGUF 文件扩展名本身不证明引擎兼容。

权重来自固定修订 `cswk/sayit-asr-gguf@d686eb53176aa2e136fb80869fddbb41fc5ef3dc`，495831520 字节，SHA256 `41c99fa5fb6f3d35f68e79adc3e755eca2232a8d921178bd647b71194792b8fd`。转换来源及运行库许可见随组件分发的 `local-asr/licenses.txt`；[原模型](https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b) 采用 OpenMDW-1.1，模型权重按需下载。

原位持续草稿使用 faithful-v4：模型接收当前块完整有效正文，可依据后文修正块内前文，只返回该块正文。2000 Unicode标量块、512标量只读前文、32KiB消息、4096输出tokens与16KiB正文分别受限；模型不授予范围写权限。旧策略与历史faithful-v3快照保留。结构与成本证据边界见 [持续草稿](revisable-draft.md)。

模型设置支持多份 OpenAI 兼容 Chat Completions 和千问/豆包流式语音配置，两种用途分别指定默认。保存不发请求，文字测试和真实录音由用户主动触发。新增或显式选择语音默认只接受已实现的语音协议；旧 Chat 语音默认迁移保留并提示补充协议。浏览器是内存模拟。语音地址、参数及未验证事项见 [speech.md](speech.md)。

## 在应用中配置

设置 → 模型包含“语音识别”和“文字处理”两个页签，首次打开语音识别。

- **语音识别**：选择“Qwen Audio 3.1 · 实时识别”、“Qwen Audio 3.0 · 实时识别”或“豆包 Seed-ASR 2.0 · 实时识别”，粘贴 API 密钥，点击“保存”，再点击“去首页试说”。新配置默认3.1，保存本身不录音或调用服务。
- **文字处理**：直接填写服务地址（URL）、API 密钥和模型。新地址预填 `https://api.openai.com/v1`，模型为空，按服务实际名称填写。保存与“测试连接”分别执行。
- 语音的“获取 API 密钥”按所选服务打开官方帮助或控制台。名称自动生成，可在“更多设置”修改；语音服务地址也在其中。文字服务地址始终直接可填。
- 首份适用配置自动成为当前模型；后续点击模型卡片明确选择。已有配置可在“⋯”菜单编辑或删除，删除当前模型前展示替代结果。
- 编辑时已保存密钥不会回填；留空保留，填入新值替换。已有配置的名称、地址、用途和身份保持不变。自定义语音模型 ID 显示为“当前自定义模型”，只有明确选择预设才变更。
- 语音预设分别保存 `qwen-audio-3.1-asr-flash-streaming` 与 `qwen-audio-3.0-asr-flash-streaming`，两者共用千问适配器；豆包预设保存 `Doubao-Seed-ASR-2.0`，由豆包适配器映射为 `bigmodel` 和2.0资源。预设不代表服务器返回的可用性列表，真实可用性需主动试说。
- 旧 Chat 语音配置仍可在文字页签管理，编辑保留其已有用途；实时语音需另加流式语音配置。

类别页签采用公共选中动效，选中项黑底白字，文字不随表面形变；减少动态直接切换。短表单的操作区跟随字段，长表单在唯一内容区滚动，操作区保持可见。关闭按钮、Esc、遮罩和离开模型面板使用同一修改保护：预填内容不算修改；有修改时选择“保存”或“取消”。保存成功后继续原关闭或切换操作；取消返回编辑并保留填写。保存失败保留输入并定位到相关字段，保存期间防止重复提交。主动取消编辑或保存后清理草稿密钥。文字检查不与保存合并，切换或关闭取消检查并忽略迟到结果。

## 职责与依赖

`features/models → ModelConfigPort → adapters/models-tauri → models/commands → ModelService`。
服务协调现有 DataWorker、Windows Credentials 和 Provider；Repository 在同一个 SQLite 工作线程上执行事务。词典不依赖模型模块，Runtime v1 不保存模型资料或密钥。页面不直接调用原生接口，凭据和网络使用小接口，不建立通用插件平台。

`models/types.rs` 定义请求、稳定错误和用途；`repository.rs` 负责事务；`credentials.rs` 串行执行系统凭据调用；`provider.rs` 复用异步 HTTPS 客户端；启动层创建独立 `network::RequestCoordinator`，文字检查和语音共用四个名额、取消与退出信号；`commands.rs` 只接受主窗口调用并记录白名单诊断。主窗口和悬浮窗原有运行协议保持不变。

帮助操作由适配层调用 `model_help`，原生层只接受主窗口和固定 `qwen-api-key` / `doubao-api-key` 标识。官方地址在原生端固定，不接受前端 URL 或路径；renderer 没有通用 opener 权限。

## 数据与默认关系

迁移 `002_models.sql` 增加 STRICT 配置、默认关系和凭据操作记录，不修改 001。配置 UUID 稳定，名称允许重复；记录和默认关系分别具有版本。配置与默认选择在同一事务读取，修改检查预期版本。

名称为单行 1–64 个 Unicode 字符，模型 ID 1–256。服务基址为不含内嵌认证、查询或片段的绝对 HTTPS URL，最长 2048 字符；只规范尾部斜杠，不自动加 `/v1`。用途至少一项。SQLite 保存名称、协议、地址、模型、用途、随机凭据引用、版本和 UTC 毫秒时间；不保存 API Key。

配置按创建时间升序、ID 升序排列。主键、凭据引用唯一约束和默认用途主键覆盖当前查询，无额外猜测性索引。首次保存填补相应用途的空默认；后续新增不覆盖。删除或移除用途时，按稳定排序选择剩余适用配置，无候选则清空。确认展示预计替代结果，提交同时检查配置、默认版本及替代结果；变化返回 conflict，不能静默覆盖。

## 密钥与恢复

语音协议迁移003在同一事务重建模型/默认关系并恢复约束，不修改002。自动填补及替代默认只选择当前可执行的协议：文字为 openai-chat，语音为 qwen-audio-streaming / doubao-asr-streaming。005扩展协议约束，既有001–004保持冻结；保留既有配置、默认关系、凭据和历史。迁移保留的旧 Chat 语音默认不能录音，需用户明确补充；不自动猜测或发送音频。认证协议变化也要求 replace，不能保留旧密钥。

Windows 使用 keyring 3.6.3 的 windows-native 后端，没有明文降级。命名空间为 `local.sayweave.skeleton.dev` / `.release`；隔离验收为 `.acceptance.<UUID>`。数据位置沿用 [本地数据说明](local-data.md)，开发、发布与测试隔离。

读取只返回 present / missing / unavailable，不返回密钥或凭据引用。编辑的空输入表示显式 keep；新输入表示 replace。显隐仅作用于本次草稿。千问3.1/3.0切换保留同服务地址和草稿密钥；跨千问/豆包切换填写对应默认地址并清空草稿密钥。已有密钥不会跨协议保留，同协议的自定义地址保留。密钥 trim 后为 1–1024 字节可见 ASCII，满足认证头限制。源站（协议、主机或端口）改变时 keep 被拒绝，保存、列表和测试规则一致。同源路径变更可以保留。

替换顺序为：写数据库 prepared 记录 → 写新随机引用的系统凭据 → 再检查版本并提交配置/默认关系 → 同事务记录旧引用 cleanup → 删除未引用凭据并清除恢复记录。失败前的已提交配置保持有效；提交后的清理失败返回保存成功和 cleanupPending，允许重试。模型管理初始化或显式重试时恢复已记录操作，启动不会自动测试网络。

恢复只处理当前数据库明确记录的 UUID 引用，删除前再次检查当前配置是否引用它；数据不可用则停止清理。恢复旧数据库可能引用已清理密钥，需重新填写，不能自动覆盖当前文件或扫描其他应用凭据。备份只包含非秘密资料与引用。不要把密钥、原始服务响应或认证头写入报告。

## 网络契约

- 文字配置在 URL／密钥失焦或打开模型选择器时同步列表，无需先填写模型名。GET `<base>/models`：15 秒总预算、5 秒连接预算，解析 `data[].id`、去重。列表可搜索，结果只表示服务返回的模型 ID；可用性由用户主动测试确认。失败、空列表或服务不支持时仍可手动填写；不改变已有选择或默认关系。
- POST `<base>/chat/completions`：固定 `Reply with OK.`，非流式，输出预算 128 tokens；不发送用户正文、词典或历史。
- 测试与实时整理共用参数构造和兼容循环。默认 max_tokens，明确拒绝时可切换 max_completion_tokens 一次；思考参数也只允许一次明确拒绝后的调整，两类调整合计最多三次请求并共享原截止时间。认证、网络故障或已经出现输出时不重发。
- 成功要求非空可见文字；空输出单独返回 emptyText，不把请求接受视为模型可用。
- 正常证书验证、禁止重定向、响应体最大 1 MiB；最多四个请求，超额 busy。请求 ID 必须为 UUID。
- 草稿变更、关闭编辑或离开面板使旧结果失效并取消请求；取消不保证撤销服务端计算或费用。结果不持久化，不把一次测试速度当作识别速度。

错误代码见 `src/contracts/models.ts`，覆盖输入、冲突、忙、数据/凭据不可用、源站变化、权限、认证、限流、超时、网络、协议、取消、超限、空文本及服务错误。界面文案与底层错误分开，不显示原始服务错误正文。

## 生命周期与诊断

系统凭据在串行阻塞工作环境执行，不占数据库线程。模型保存门保证一次协调写入；网络不持有数据库或 Runtime 锁等待。退出停止新操作，取消网络和演示，等待已准入数据/凭据操作，最多 5 秒，超时依靠事务和恢复记录。

日志由 tauri-plugin-log 2.8.0 输出到对应数据环境的 logs 目录及标准错误，单文件 2 MiB，保留三个历史文件。仅接受 sayweave 目标的白名单操作、UUID 请求、阶段、耗时和稳定错误码，不记录路径、完整 URL、正文、密钥或词典内容。日志失败不阻止主要功能。

## 验证与边界

自动测试覆盖迁移、默认冲突、源站绑定、凭据失败和清理、实际子进程在 prepared / written / committed 阶段退出后恢复、受控 HTTPS 协议/上限/取消。真实桌面测试使用独立数据库与 Windows 凭据，三次退出重开验证持久化。测试证书仅由 desktop-acceptance + UUID 环境启用，正常构建不允许注入测试信任或验收退出命令。

供应商实测需用户在应用内提供配置，无凭据时保持未验证。实时语音的实际录音入口独立于文字测试；本地识别见本文开头。Responses 专有协议、自动重传、账号或云同步不在当前支持范围。完整测试命令见 [testing.md](testing.md)。

## 实时整理开发契约

当前开发分支将外部原位口述的稳定ASR语段交给默认文字配置，关闭整理后仍保留直接原位识别。设置使用显式保存和记录版本，任务开始固定模型、词典及设置快照。已有凭据、默认关系、HTTP客户端和四个网络名额继续共用。没有可用文字配置时沿用识别原文。

文字请求使用OpenAI兼容Chat Completions与SSE。每次上传一个冻结语段及有限前文；完整、正常终结且通过校验的输出才能应用。部分流、截断、拒绝、错误及意外断流保留原文。总15秒保护包含名额等待和请求；最终阶段共用剩余预算，不能把保护上限当作固定延迟或性能成绩。参数兼容规则与主动测试相同。

自动低思考策略独立位于 `models/latency.rs`。已知服务发送相应关闭参数，已知强制思考模型使用已支持的低档；严格服务保留例外。自定义兼容端点采用关闭参数，并只根据明确的参数拒绝调整。有效组合按完整端点、模型、凭据指纹、配置代次与策略版本隔离缓存；配置保存清理缓存。没有思考档位控件，也不保证任意服务都支持关闭思考。行为参考 SayIt 固定提交 `9158443e2c9d4d042ea6ff5c259633363128088d`，本项目独立实现请求策略与测试。

模型列表为15分钟进程内缓存，URL、编辑记录版本及密钥指纹参与隔离，不缓存密钥原文。相同编辑器在途请求合并，刷新可跳过已完成缓存。编辑器代次阻止旧响应覆盖新草稿；关闭或切换配置会取消请求。语音入口继续使用固定预设，不自动探测或付费测试所有模型。

提示词由固定规则、当前任务、相关手动词典、有限上下文和正文数据按同一入口组装。当前输入最多512个Unicode字符；词典最多32项及1000字符，上下文最多512字符，完整消息12KiB。长网址、路径、代码及字素不可拆开时保留原文。正文中的问题或命令作为口述内容，不执行或回答。整理的忠实度通过提示词约束和人工评测改善；客户端不按数字、否定词、保护片段出现次数、代码包装或输入输出长度比例否决完整模型正文。模型响应必须完整、非空且不含不可用控制字符；任务来源、修订和原生范围归属另行验证。

历史原始识别独立保留；整理结果是另一版本，不代表用户后来在目标软件编辑过的最终正文。数据、目标文字和网络结果各有状态，保存失败不撤回已经输入的文字。具体草稿契约见dictation.md，受控验证不代表真实文字服务质量。

功能开关即时保存。整理口述在文字模型列表上方，个性化有独立设置入口，自动入词位于词典页；开关不要求额外保存，也不触发表单离开确认。学习设置直接读取与保存本地设置，不依赖模型列表或模型状态读取成功。
