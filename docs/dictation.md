# Windows 跨应用口述

当前默认采用持续草稿：停顿或一次模型整理不会固定前文，当前块内手动编辑后仍可重新接管并整块整理。既有正文和已交付块不自动纳入。下文旧分段策略仅用于受控内部回退；默认行为以 [持续草稿](revisable-draft.md) 为准。

口述快捷键默认是右 Alt。在设置的「设备与快捷键」中，可录入单键或组合键，选择按一次开始／结束，或按住说话／松开结束。点击键位框直接录入，组合键分别显示；Esc、点击框外或窗口失焦退出录入，保留原设置。完整录入后自动保存，取消录入不保存；录音方式选择后即时保存。界面分别显示保存值与实际启用值；任务中保存的设置在当前任务释放后注册。

同时使用其他口述工具或输入法快捷键时，为各工具设置不同键位。组合键注册可以报告系统注册冲突；单独修饰键监听成功只表示监听已启动，不能检测其他程序是否拦截了同一按键。

## 职责与任务边界

`shortcuts` 将 Windows 物理键状态与官方组合键注册转换成带配置代次、按键代次的事件。右 Alt 与 AltGr、左右修饰键分开，忽略注入键和长按重复。自行消费的按键以实际 hook 松开事件结束；活动组合键中未消费的成员补充异步状态检查。每次按键的消费归属在捕获失焦等提前返回之前结算。设置录入有超时、关闭和页面重载清理。

快捷键状态快照带单调序号，读取和命令响应与事件使用相同顺序；设置和首页只接受新快照。每次录入携带独立随机身份，原生状态在录入结束后仍保留该身份，设置只消费当前编辑器拥有的录入。放弃、关闭或离开后，旧捕获结果不会进入下次草稿，准备期间收到其他状态也不会清除本次录入归属。

`dictation` 在异步准备前预约任务身份，绑定来源与原生目标，接续 SpeechService 的终结结果。应用内试说、历史重识别与外部口述共用准入；外部任务直到交付结束才释放。控制和当前录音重试绑定显示任务 ID；悬浮展示使用独立 presentationId，关闭和复制同时绑定任务及展示身份；按键同时绑定触发时的任务与准入代次。配置注册和落库期间暂停新准入，旧配置事件、旧 Esc 与旧终结结果不能控制新任务。

SpeechService 拥有录音和识别生命周期；供应商适配器、音频文件和历史职责保持独立。Runtime 管理窗口阶段投影。前端只显示状态，不决定输入目标或供应商协议。

持续输入分为 Session、Turn、Draft。Session 拥有一次口述的资源、模型快照与历史；Turn 绑定当前编辑位置和识别连接；Draft 管理目标进程 TSF apartment 中的组合范围与版本。主程序接收原生识别 watch，将当前轮累计文字更新到同一范围，最终提交等待最新版本应用。主程序不保存外部 COM 对象，也不以反复粘贴整段文字模拟原位更新。

组合对象结束与整个口述任务结束分别结算。提交前段后尾部为空时，自有结束操作绑定任务、操作、revision、代际及组合对象，匹配的同步结束回调不能提前释放逻辑草稿；后续仍须核验原范围和选区。空对象、旧对象及旧代际通知不释放当前草稿，真正结束当前组合的外部通知保留明确的 `draftOwnershipTerminated` 原因。编辑通知内只读，真实外部编辑和不确定写入继续走现有保护。

草稿协调器保留首个因果错误，后续结算失败单独记录为有界诊断，不用 `staleSnapshot` 覆盖更早的输入失败。取消、回滚失败和不确定输入效果保留各自事实。正常空结果、取消和已交还用户正文后的正常结束安静收起，即使同时收到无写入的目标切换、只读或编辑交接拒绝。原生任务所有者决定终态；前端只投影相同任务、来源与展示身份，不从历史任务或迟到状态生成通用识别失败提示。开始前的配置／权限阻塞、保存失败、恢复失败及不确定输入效果继续显示准确原因，历史和诊断仍保留真实结算事实。

悬浮控件在所在显示器工作区底部中央，可见胶囊底边距工作区底部10逻辑像素，包含透明窗口内10逻辑像素的底部留白。首次显示、窗口展开／收缩、移动和缩放共用实际外框定位；任务、展示代际与窗口实例保护保持，窗口不激活、不抢焦点。

实际键盘或鼠标编辑先撤销写许可并交还组合，原块保留只读跟踪。输入法组词完成后，协调器在原期限内核验连续范围、当前正文和选择，恢复同一块的 Draft；租约刷新不重启识别连接、不重复消费旧来源。仅移动光标暂时无法映射来源时继续只读等待，不能把它当作真实编辑基线或永久范围失效。真实块内编辑形成新基线；范围越界、文档重建或身份失效才采用新位置路径。绿色结束收尾最终来源，×停止录音与后续应用并保留已显示正文。详细状态、来源水位和不确定写入处理见 [持续草稿与编辑接管](revisable-draft.md)。

`windows_input` 在专用 MTA 线程探测目标性质并串行处理主动复制。UIA 检查密码、只读及身份，组字冲突由 IMM 明确信号及实际 TSF 上下文检查；读取不足不会解除当前任务的共享目标绑定。窗口身份及用户活动归输入层管理，实际选区和组合范围归目标进程中的 TSF 组件管理。外部文字、剪贴板及密钥不进入诊断日志。

## 悬浮展示与正常结束

点按和按住均在按下时立即显示准备动画，服务与设备就绪后才显示录音波形。点按再次按下结束，按住松开结束；准备中提前结束则取消启动。采集对象在等待设备准备前建立停止归属，取消后迟到的准备不能启动麦克风。

正常结束停止采集、排空已采集 PCM、发送协议结束指令并继续接收最终结果。正常悬浮反馈由现有动画表达准备、录音、识别和完成阶段，阶段名称仅用于原生状态、日志和无障碍标签。正常提交后停留约600ms并收起；输入异常时显示具体提示，不重复提交或展示复制框。提示可关闭，也在短暂停留后收起。没有输入目标的结果框保持可复制和可关闭，复制成功后短反馈收起。

关闭展示不删除历史，也不取消仍在运行的识别。新任务有新的展示身份，旧关闭和定时器失效。字幕只用于录音阶段，最终反馈不依赖正文是否存在。后台识别和展示隐藏分别管理。

音量从本地采集的50ms窗口聚合，独立于网络发送发布；波形以20Hz更新真实音量，快速上升、平缓回落。减少动态时保留音量变化，隐藏或结束后停止绘制。

## 原位输入与准入

有可编辑位置时，外部口述先绑定目标、检查共同安全属性、查询当前用户组件状态并建立 TSF 草稿，之后启动录音。没有输入位置，或原生检查明确当前区域只读／不可编辑时，使用相同录音流程，结束后展示复制结果。UIA 缺少文本模式或读取失败不能独自证明没有输入位置，仍由原生上下文完成准入；密码、权限、安全属性不明和组件故障保留原有拒绝。任何准备阶段的写入资源都须先结算，清理失败不能进入复制录音。

复制模式在本轮开始时固定，之后点击输入框不会向其中写字；下一轮重新判断位置。结果中的“复制”才修改剪贴板，关闭保留历史；空口述和取消按原行为收起。该模式记录 `copy / notSubmitted`，不附加输入组件中断错误。已经写入或写入效果不确定的任务继续按原有输入结算，不转为这条启动分流。

设置查询与实时输入准入复用同一组件状态入口，区分未安装、未启用、查询失败、版本不匹配及目标组件尚未就绪。机器级安装完成后，发起操作的普通用户进程负责启用并回读验证；管理员帮助进程不代表日常用户的启用状态。

原生快照的 `inputRoute` 表达 `none/live/resultOnly`，`admission` 表达 `pending/ready/rejected`。有目标但草稿准备失败会结束准备、释放资源并给出设置入口。无目标结果可复制和关闭。运行中原位置失效或输入效果无法确认时，先撤销后续写入并结算在途操作，保留识别与真实波形，转入本轮固定的结果模式。用户结束后保留完整口述原文并复制一次，复制失败仍显示结果；取消不自动复制。已写入事实与复制结果分别记账，不向新焦点重发正文。

### 应用、编辑端点与原生文档

应用身份保存外层窗口、进程及创建身份，用于前台归属和应用偏好；编辑端点保存实际焦点 HWND、进程、线程及创建身份，用于 TSF 通道与组件身份核验。跨进程子编辑器以窗口、焦点和文档视图证明所属，保留认证和载荷核验。

原生输入在 Begin 从活动线程的 GetFocus／GetTop 取得输入上下文，仅在已枚举的 `GUID_COMPARTMENT_TRANSITORYEXTENSION_PARENT` 关系及父接口有效时选择持续文档；可选父属性为空、类型不符或接口不支持不单独否决普通输入。文档选择由现有会话状态保存，组合交还后由连续块保留同一身份；后续只核验已选路径，不因父能力出现或消失重新选择。明确的安全拒绝和身份矛盾仍阻止写入。组合写入、连续跟踪、键盘交接和原块接管使用同一解析结果。UIA／MSAA 补充控件与语义证据；明确的密码、只读和权限拒绝继续生效。

父文档的操作持有父写锁，同时在临时上下文自己的读会话中核对安全属性和组词状态，保持读锁完成正文、组合或选区操作。流式写入、整理、提交表示及回滚共用该权限入口；锁前拒绝与实际调用后的效果分别保留。纯组合释放独立结算。同步读会话返回后封闭其回调，迟到事件不能再使用父写锁。换输入框、文档退役或范围失效撤销旧资格；范围不从新焦点或文本搜索重建。

窗口层通过 `voice_window` 管理悬浮窗实例、非激活显隐和布局；任务绑定在显示之前完成。输入层按窗口实例与父子关系区分本任务悬浮窗，主窗口或其他应用切换仍是失效证据。提交前仍检查实际前台、进程生命周期、任务身份及编辑活动。共享绑定由任务建立、忘记及退出管理，UIA 探测失败不提前释放。

一次口述共用同一个 STA、组件启用租约和认证连接；轮次仅管理组合范围，通过 `begin/update/commit/handoff/abort` 交换。编辑交接不反复关闭并重新启用组件。组件在目标线程检查 TSF 当前上下文及范围所有权，累计识别更新同一范围；结束先应用最新快照再提交，取消只恢复尚持有的范围。正常口述不读取或改写剪贴板。主动复制与历史复制继续通过串行原生工作线程执行，并在写入前检查操作代次。

组件使用非前台 TSF 按键监听，只在持有组合范围时参与编辑按键处理。在实际按键回调中同步交还范围，再让原按键由目标处理；测试回调不修改状态，不吞键或重放按键。悬浮窗身份查询使用创建时登记的窗口实例，不在任务锁内同步等待界面线程读取句柄。

TSF 的 applied 答复证明组合操作已执行，不代表目标软件已完成渲染或接受了全部文字。正常提交记录为 submitted／unconfirmed，确认能力记为 unavailable；显示约600ms完成动画后收起。没有独立确认时不重复写入，也不切换复制路径。字数上限等目标软件约束继续有效；识别原文按现有历史或当前会话规则保留。

实时写入由组件的上下文、组合范围及任务／轮次／版本负责。主程序每次请求仍复核前台、进程生命周期和实际编辑活动；组件在执行时再次检查密码、只读、禁用状态及范围所有权。生产输入路径不读取整篇正文作为每次更新或结束的门槛，也不轮询 UIA 来猜测目标是否接受了提交。开始时的 UIA 只辅助检查目标性质。

真实键盘、鼠标编辑关闭旧轮写入并交接草稿，同窗控件或前台变化仍受保护。部分浏览器在组合期间不会把网页脚本单独移动光标的变化通知 TSF；这种情况下旧组合可能继续在原范围更新并移动光标。此项为已接受的兼容限制，保留复现记录，不代表手动编辑保护可以省略。

TSF 的属性通知与文字、选区修改分别处理。覆盖整个组合范围的统一整数属性可随更新重设并回读，累计最多64项；局部、混合、删除或无法保留的属性交还范围。发生外部属性变化后，原撤销备份不再有效；取消结束组合并保留可见文字及属性，报告撤回未完成。普通 EDIT 的系统桥接属性也遵循此边界，不按属性 GUID 或进程名放行。

输入组件将原始语义文字与临时组合表示分开。组合阶段的换行使用保持连续范围的临时软换行表示；原文中的真正 U+2028 不被反向替换。正常提交在同一次 TSF 写会话内恢复原始换行语义并结束组合，避免富文本编辑器提前拆段后再次追加文字。转换与提交不使用剪贴板，也不在完成后补写纠正。清理具有独立身份；正文、选区或属性被外部修改后撤销转换权限，资源仍能结束，不能覆盖用户编辑。写协议10在每次操作中绑定代理实例和核心代次；首次代理迁移或代理自身升级可能需要重开输入目标。原生控件、textarea、contenteditable 与 ProseMirror 多行实际正文断言分别留证，组件答复仍保持 submitted／unconfirmed，不充当独立渲染确认。

## 数据与权限

迁移 006 新增快捷键设置和交付尝试；001–005 保持冻结。设置使用版本检查。交付记录只保存关联识别尝试、状态、时间与稳定错误码，不重复保存正文、目标或剪贴板。历史关闭时交付只在内存中。历史启用但存档／交付登记失败时停止填入，保留应用内结果。

启动恢复将 pending／delivering／submitted 标为无法确认，不重复输入。历史展开区按识别版本查看填入结果；列表继续展示识别内容。

主窗口可管理快捷键和读取历史交付；悬浮窗仅操作当前任务、复制当前无目标结果；准备被拒绝时可通过绑定任务及展示身份的固定命令打开主窗口设备设置。前端没有通用 UIA、任意 HWND、任意路径或剪贴板读取入口。悬浮窗不可聚焦；显示、字幕更新和窗口显隐不改变任务目标。 Windows 显隐统一走非激活原生入口，尺寸／位置继续使用非激活路径；创建后不修改悬浮窗的聚焦、装饰、置顶或最大化标志，避免底层窗口库的可见状态覆盖原生显隐。

## 验证

`npm run check` 与 `npm run test:e2e` 检查类型、组件、契约、生命周期和既有流程。`npm run test:input` 在自己启动的空白编辑器检查结束前两次原位更新、选区替换、Unicode、交接和目标变化保护，并核对剪贴板序号不变，不复用个人文档。`npm run test:desktop` 使用独立 UUID 数据目录验证窗口与退出。

`scripts/test-speech-desktop.mjs` 验证录音到交付的原生受控闭环。可编辑的 input、textarea、contenteditable 和 ProseMirror 必须实际得到预期文字；被拒绝或出现复制结果不能代替成功断言。测试依赖的 ProseMirror 包仅用于受控目标，不进入产品页面。

`SAYWEAVE_SPEECH_ACCEPTANCE_SCOPE=result-only` 选择同一入口的无输入位置检查：受控供应商先等待启动路由确定，再发送识别结果，核对实际音频帧、焦点改变后的正文、结果操作及复制交付历史。`SAYWEAVE_BLOCK_IME=1` 选择现有富文本入口的真实输入法对照，使用自有编辑器和受前台保护的按键，分别检查直接打字、结束口述及停止口述后的英文正文；报告不代表偶发故障已自然复现。

悬浮按钮验收使用 DPI 感知的隔离辅助程序，通过真实 Win32 鼠标按下／松开发送到已核实的悬浮窗按钮；浏览器调试点击不能替代此路径。用例同时断言原生 Edit、浏览器与富文本的实际插入、选区替换、Unicode及连续任务。切换窗口后切回或打开主窗口后切回，必须停止旧任务继续写入；真实用户编辑走草稿交接，迟到结果不得覆盖用户文字。报告绑定启动的 EXE 哈希、PID、隔离数据目录和实际子进程诊断流，文件视图不一致时不以旧路径内容解释新任务。日志不含外部标题、正文、剪贴板内容或密钥。

实际兼容性按 Windows 控件和应用版本分别登记。隔离原生编辑器、浏览器界面测试与供应商口述是三类证据；一种通过不能代替另外两种。个人截图、性能记录和供应商验收留在本地 Change 中，未完成的项目不得标为已通过。

## 状态接续与扩展

SpeechService 通过原生 watch 订阅输出生命周期，通过终结通道交付最终结果。启动层连接口述协调器与 Runtime 投影；语音服务不调用具体口述协调器。历史服务拥有交付记录和启动恢复，快捷键服务只管理触发配置。口述协调器在资源整理和任务准入释放后发布可操作的结果展示。显示与收起使用任务和展示身份，旧操作不能作用于新任务。

主程序与输入组件通过当前用户 ACL 限定的命名管道通信。临时主机身份使用同一会话的命名共享内存，记录进程创建身份和随机能力标识；发布后不可变，释放前失效。握手和每次编辑都复核管道客户端、进程生命周期、会话及能力标识。注册表只负责组件注册，不承担临时握手通信，避免打包应用与日常进程看到不同视图。组件不按应用名称放行。

正常外部输入使用 TSF 原位草稿；不可用时明确终止准备，不以最终粘贴代替实时输入。组件维护与任务共用准入，前端不能传入 DLL 路径、注册表路径或外部目标。

处理模块消费绑定版本的原文，输出独立结果；发送模块独立管理发送动作。原始识别记录保持独立，处理失败或用户外部编辑不覆盖它。分段整理的开发接续见下文；翻译与自动发送未接入。

输入组件独立检查 TSF 当前上下文的禁止输入和空上下文标志；标志非零或读取失败时，不建立或更新草稿。该检查与输入范围的密码属性、主程序目标保护分别保留。

建立草稿前，在同一认证管道先执行控制协议1的 `PrepareEngine`，核对固定代理与执行核心的实际模块、受保护文件字节及哈希；随后 `Inspect` 和 `Begin` 绑定同一代理实例与核心代次，写协议为10。范围、编辑会话、观察和未结算回执仍属于其原核心，不迁移正在口述的组合。结束旧观察并读取已有学习变化后，下一轮可在原 STA 安全点切换。允许退役旧模块并存，不能以同名模块数量判断执行身份。实际接入效果仍由对应宿主的输入验收证明。

固定代理拥有 COM 服务对象、认证管道及 STA 窗口，核心通过 ABI1 的不透明句柄和调用方缓冲区处理输入。实例、回调、编辑会话及模块租约归零且 `DllCanUnloadNow` 允许时才释放模块；加载、COM 调用及卸载不在全局模块锁内执行。候选激活失败先停用候选，再恢复旧实例；执行身份不符或无法安全退役时拒绝新写入，不回放正文。普通管道保存每个业务回执，只有原控制进程创建身份及能力标识匹配、原 task/turn/operation/revision/代次与字节哈希被确认后才结算。断连恢复只读取原回执；迟到的观察答复与控制确认在有界收件缓存中分别路由。


## 内部旧分段策略的输入契约

`sayweave-streaming-polish-v01` 的协议8候选增加 `Settle`：在同一个组合范围和写会话内提交整理前段，移动组合起点，尾部继续由原范围持有。答复分别报告前段修改、原操作身份和尾部所有权；成功答复不代替目标正文验证。阶段C组件验证后，开发分支已接续外部口述整理业务；当前验收与已集成主线范围分别记录。

分段边界由唯一的纯函数 `SettlementBoundary` 形成：前段正文先提交，整个末尾 CR/LF 串仍属于尾部；下次提交前将旧分隔符放在新正文之前。当前提交正文、保留分隔符与来源单元完成分别记账。取消只删除仍持有的尾部，结束时只剩分隔符也要提交，用户交接后不能继续撤销该范围。仅分隔符的处理结果不产生正文提交。协议8在调度前拒绝末尾 CR/LF 前段，保持原草稿和连接，不通过断连清理来拒绝它。

这个边界避免把“提交末尾换行后的缓存光标”当作可靠的新段输入位置。标准 Chromium 插入同样复现了该位置问题，故实现不增加应用名单、猜测偏移或固定等待。拒绝回复与操作终结分开；重复请求不能删除正在等待的分段操作。实际原生、浏览器、Codex以及产品记账验收仍分别执行。生成尾部的取消只删除仍由本任务持有且内容未变的原范围，不寻找新输入位置；原选区恢复和正常写入继续校验光标。

## 内部旧分段策略的整理契约

非空初始选区先进入准备状态：绑定原范围、备份和编辑代次，但不在旧选中文字上启动组合。首份非空文字到达后，在同一 TSF 写会话内替换仍归本任务所有的选区并建立组合；此前的空更新只推进修订，结束、交接或取消只释放准备状态。首字前发生用户编辑或位置变化时，旧范围失效。首字写入已经开始后的失败须报告可能修改，不能按“尚未写入”重试。

部分宿主在焦点返回后保留真实选区，但 TSF 缓存已折叠到选区末端。初始范围评估可在当前进程、线程中读取已聚焦的原生无障碍提供者；只有完整有界文档表示能精确映射、提供者身份与选区再次核实、且确属上述末端折叠差异时才修正初始范围。读取能力不足不改变通常的 TSF 路径，不按应用名放行。表示映射只接受整份正文一致或统一段落换行表示，拒绝坐标有歧义的情况。

初始取消恢复原选中文字；浏览器可以保留高亮或把光标折叠到恢复文字末端，不另行异步重选。原生备份与语义换行分别保留，恢复时在原范围和任务身份仍有效的前提下使用同一个恢复入口。备份已被用户编辑作废、或首次写入结果不确定时，不覆盖用户操作。实际目标文字与组件执行答复分别验收。

前段提交后尾部为空时，组件结束实际组合并保留原插入位置。对提供完整文档范围的上下文，写入凭据分别冻结正文、范围两端和提交后的文档终点；范围对象的克隆会随宿主编辑移动，不能代替数字位置证明。后续通知和实际执行前均复核这些证据。富文本宿主在冻结文档终点之后追加纯 CR/LF、且原正文、空插入位置和实际折叠选区均未变化时，可以继续持有原位置；新增部分不进入写入、原文或撤销范围。每个通知都须完整落在已验证写区或这段新增区，读取失败、越界、真实正文或位置变化仍撤销旧写入资格。该判断证明原位置安全，不推断通知来自用户还是宿主。标准 EDIT 的组合专用文本存储在提交后会重定位，沿用既有原生光标位置证明；非空尾部保持原有组合区保护，不套用全文位置凭据。

Session串行草稿循环维护Turn、来源Unit、已提交水位、最新尾部与原生范围。模型模块不访问Windows窗口或范围；它返回冻结来源的候选。ASR新增尾部不作废有效前段请求，来源本身改变或用户接手才撤销资格。来源校验同时检查句段身份、局部内容和实际全局位置，避免重复文字造成来源别名。同一识别快照只构建一份Unicode来源索引，已提交单位、当前请求和在途原生操作共用它；追加尾部不改变冻结跨度，重复身份或真实位置变化仍拒绝。一个有效模型请求和一个原生文字操作可以同时在途；未执行的尾部更新合并为最新快照。

原生协议8在同一自有组合写会话中应用整理前段和最新尾部，再移动组合起点。回复分别表达前段变更、剩余范围归属和错误。实际前段提交、原文消耗及保留的末尾分隔符是三个独立事实。分隔符及只含换行的语段保留各自来源，直到下一次前段或正常结束的原生回执才结算。未收到确定回执的操作不重发；组件回复不能代替目标实际正文断言。

用户编辑先交还范围，旧Turn结果不能覆盖新位置。正常结束排空音频、等待最终识别和有效整理结果，再提交当前尾部。取消保留已提交或已交还的前段，删除仍持有的尾部与整段录音；仅保留对应原文，待生成单位不进入取消后的历史。可能已经修改的单位以不确定恢复记录保留。数据库通过一个事务裁剪取消来源、整理记录并登记录音清理；历史关闭时也清除内存录音和重识别入口。退出或中断交还可恢复文字，用户明确取消的信号不能被随后退出覆盖。

首页试说与历史重识别继续使用原始识别投影；本阶段原位分段整理接入外部可输入目标，无目标的结果保留原始识别供复制。记录实际覆盖与未接入范围，不能用模型设置开启状态宣称所有任务来源都执行了整理。


完整模型正文不再按数字、否定词或改写比例作客户端语义否决；保留响应完整性与来源/范围归属。输出结束后的交付诊断留在内部记录，不显示状态解释横幅；正常完成动画结束后收起，原有无目标复制结果及准备失败入口独立处理。

最后一次精确Settle回执若已提交前段且尾部严格为空，正常收尾只释放连接，不再提交空范围。该回执在后续写入尝试或新轮次时失效；取消原子门禁、非空尾部提交与资源关闭错误仍独立处理。此路径记录原Settle的Submitted事实，不伪造新的Commit回执或宿主渲染确认。

Cancellation, rollback failure and lease cleanup are independent finish facts. A failed rollback keeps its frozen ASR recovery text through the authoritative processing cancellation journal and database reopen, with `compositionRollback`; the committed output still contains only receipt-backed text. Older cancellation journals default the added rollback flag to false.

Read-only learning observation follows receipt-backed output for up to60 seconds and normally settles after15 seconds without edits. If the same captured output range is cleared before that delay, it can settle the latest already-verified complete correction. This adapts Typeless's cached-edit-before-clear mechanism to Sayweave's receipt scope. Clearing itself is not lexical evidence or proof that a message was sent. Current and prior IME completion, field identity, edit generation, protection and source eligibility still apply; undo, restoration of original text and deletion without a correction cannot revive an earlier correction. Only the captured output range is read. Whole-field emptiness can additionally use TSF structural metadata or the length of a same-process native EDIT/RichEdit control, never a browser window's caption length.

Foreground accessibility notifications are distinct from actual activation. A live `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW` window reporting foreground while the captured top is still the actual foreground is advisory; names, classes and process IDs do not authorize this exception. Original range and execution-time target checks still apply, and an earlier confirmed switch remains invalid. If the helper actually owns foreground, automatic input stops. Ordinary external-window switch-and-return events remain invalidating. A nonactivating tool explicitly activated and returned before a delayed callback can be treated as advisory; this policy does not prove that the tool belongs to the target's IME.

## 准备范围与终态

Begin 对空光标和非空选区统一只准备范围；首次非空更新才创建原生组合。未写入的结束、取消与交接只释放本任务范围和监听，不需要新焦点可写，也不提交或恢复正文。已写入组合跨焦点交接仅在其捕获上下文的合法写会话结束组合，不向新目标写入旧识别文字。身份、代际、操作修订和组合对象仍约束所有回调；拒绝结束时保留实际范围和恢复事实。

普通投递 pending/delivering 记录在后台归档，不作为输入激活门禁；取消与正文恢复的安全意图仍由原生所有者处理。空结果、取消、只读以及结算安全事实不弹遮挡目标输入框的长条提示；安静投影不改变输入效果、首个错误和历史诊断。真正不确定的效果阻止后续不安全写入，终态不能由迟到准备或识别事件重新打开。

Observation retirement shares one connection-owned completion between automatic expiry and explicit close. Completion is published after Host resources and the activation lease have been released; command-channel closure is not proof of either success or failure. A retained connection remains tracked through cleanup, and only its confirmed successful completion clears that exact slot. Failure stays attributable and blocks the next admission. Waiting consumes the existing preparation deadline and supports cancellation without abandoning the old cleanup.
