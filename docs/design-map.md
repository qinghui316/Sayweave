## 配色

基色：白 #FFFFFF、浅白 #F6F6F6、灰 #CBCBCB、黑 #000000、绿 #75FB91。
语义参数见 src/design/tokens.css：侧栏灰24%、快捷键灰48%、工作区/底片灰38%、辅助字黑64%、遮罩黑28%。白色主体；不使用绿色文字/数字；导航选中黑底浅字绿图标。分组依赖表面与留白，没有默认装饰分隔线。

字体 Noto Sans SC 400/500/700，品牌 Inter 600。当前桌面首页32/44，模式16/24，说明/按钮13/20，导航14/22，主用量40/52，普通标题24/32。冻结Figma原字阶保留为历史，当前代码的紧凑适配来自用户2026-10-03实机复核，不是悄悄统一32/32与32/44的画布差异。

冻结画布基准1440×1024。当前桌面侧栏184、内容28；三模式同级64、图标20、按钮148×36；导航选中不改字体和几何。用量252×238、灰底252×238左露10下露14；模型准备与试说合244高工作区。字号固定，采用局部布局和必要滚动。960×640是当前 native 技术保护值，不是最终产品最小尺寸承诺。

用量使用浅白82%、绿色26→40%、白高光24→6→0、blur16、黑7%阴影(0,5,16)。设置blur10、遮罩28%、白面板、黑20%阴影(0,16,48)。CSS 多背景层对应填充堆叠，WebView2 呈现仍需实机对照。

## 当前范围与补充

首页零统计真实、快捷键/模型未配置。快速试说按钮明确预设演示。设置与关于同一壳层五个同级入口，单列内容；模型完整表单下一阶段，当前不伪造保存/测试结果。历史/偏好/首次使用为预留入口；词典已有真实手动CRUD，持久化规则见 [local-data.md](local-data.md)。

新增 hover、可见 keyboard focus、禁用、加载为骨架补充，不伪装成已绘制 Figma 状态；Radix 管理 dialog/select/switch/tabs 的可访问性。Dialog Esc 关闭并恢复触发按钮。动效280ms、减少动态120ms；尚未实现全部17/11变体、真实音量及连续材质光效。

## 当前启动尺寸

初始1120×760逻辑像素，工作区约90%上限、960×640技术保护值；960至1440宽度均保持快捷键和用量并列；窄窗口收紧内距，用量宽232。1440×1024仍保留为设计对照，页面内容滚动而非整体缩放。用户于2026-10-03指出过大后调整；未更改冻结Figma。
