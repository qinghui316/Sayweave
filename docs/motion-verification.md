# 交互动效验证

实现规则见 [motion.md](motion.md)。公共组件与语音使用同一动效策略；开发样例只在 DEV 页面，生产导航不包含组件展示。

## 可复现检查

`npm run check` 验证反馈组件、异步代次、协议与原生缩窗；`npm run test:e2e` 检查密码连续显隐不丢值/选区/焦点/几何、模拟复制成功和失败、受控连接状态、正常与减少动态。`npm run test:desktop` 在真实窗口中检查处理到完成、两窗同步、取消、失败、快速重启及旧缩窗拒绝。

观察默认1120×760和缩窄窗口：文字与数字不使用绿色，选中导航不改变字号和图标位置。处理/完成/失败之间 SVG 实例稳定；首次直接绘制，快速切换追随最新目标。

复制等待传入 Promise 成功后停留1500ms；新请求、旧结果、计时器与卸载不会覆盖新状态。连接反馈由外部驱动，不发真实网络请求。密码显隐只改变显示方式，不改值或输入节点。

窗口隐藏、离开可见区域、设置遮挡背景或减少动态时暂停循环；恢复显示最新状态，不重播旧完成反馈。原生扩大先保留画布，320ms后仅匹配 revision/session 才收缩。

## 性能和覆盖边界

浏览器流程输出截图与帧采样到忽略的 `tests/visual/`，这些是本次运行产物，不是生产素材。减少动态检查持续动画数为零；浏览器帧采样不能证明 WebView2 原生 FPS。

曾在 Windows 150% 下观察到录音演示进程树负载明显高于待机，有限的图层调整未证明 CPU 下降。保留为渲染性能专项，不宣称优化完成；原生逐帧视频、跨电脑 CPU/GPU 预算和其他系统缩放仍待验证。

胶囊280ms有限尺寸过渡是已确认的状态形状表达；波形循环采用 transform/opacity。项目 `.impeccable/config.json` 仅对该语音样式的 layout-transition 检查保留窄范围例外，不全局关闭检查。

普通构建独立运行与 DEV 排除均需复验。真实音量、录音、模型与系统输入不由此演示证明。
