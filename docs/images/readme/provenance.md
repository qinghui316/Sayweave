# README 素材来源

## 品牌

`brand-light.svg`、`brand-dark.svg` 组合自产品的 `src/assets/brand.svg` 与 `src/assets/wordmark.svg`。保留原矢量轮廓，仅调整组合尺寸和深浅背景下的前景色。

字标基于 Newsreader Italic 的路径图形，许可见 [Newsreader OFL](../../../src/assets/licenses/Newsreader-OFL.txt)。

## 六段交互演示

`hero.gif`、`comparison.gif`、`cleanup.gif`、`handoff.gif`、`dictionary.gif`、`personalization.gif` 复用 Sayweave 官网的对应场景、组件与确定性时间轴，来源提交为 `72a96c1709d8186ba07a94a32db82c19bba815d6`。

导出保留完整场景时长，裁去重复标题和外围留白，再转换为 GIF。前四段为20fps，词典与个性化为15fps。文字与波形由官网场景时间轴驱动。

界面字体为 Inter、Noto Sans SC；许可见 [Inter OFL](../../../src/assets/licenses/Inter-OFL.txt)、[Noto Sans OFL](../../../src/assets/licenses/Noto-Sans-OFL.txt)。背景沿用官网原创水彩资源。控件、图标及相关许可沿用产品 [NOTICE](../../../NOTICE)。

## 界面截图

`home.webp`、`words.webp`、`history.webp`、`appearance.webp` 来自产品提交 `b525e2fd7583e8907a2c72ca2e48bce9eeaca2e3` 的正常页面，1120×760逻辑像素、1.5倍采样。

截图使用产品前端入口、原有组件和布局，由浏览器渲染。记录、词条、设备及配置元数据通过内存适配器提供。

文件尺寸、时长与 SHA-256 见 [素材清单](manifest.json)。
