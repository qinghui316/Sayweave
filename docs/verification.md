# 骨架验证与覆盖边界

验证以源码测试和真实桌面运行分别记录；生成截图、日志、运行标识与机器报告保存在本地，不随源码分发。此文说明可复现的方法，不作为任意电脑上的通过保证。

## 复验步骤

按 [开发说明](development.md) 准备环境后执行：

```powershell
npm.cmd run check
npm.cmd run test:e2e
npm.cmd run test:desktop
npm.cmd run desktop:build
```

`check` 覆盖类型、lint、模块边界、循环依赖、UTF-8、前端测试、Rust fmt/check/Clippy/测试和前端构建。E2E 覆盖共享设置弹窗与焦点、固定导航几何、演示完成/取消/失败、词典页面、布局及中性文字。

原生验收使用显式 `desktop-acceptance` feature，在实际 Tauri 进程中调用托盘回调共用处理器并操作窗口。脚本会打开、隐藏、恢复、关闭自己的测试窗口；它不持续控制用户输入，也不证明任务栏实体鼠标点击路径。普通构建不编入验收入口。

开发启动器检查重复启动、重启、停止和进程所有权；只清理所属 Windows Job，拒绝伪造 PID。端口占用时报告原因，不结束占用者。依赖缺失时提示准备环境或 `npm ci`。

## 桌面基准

初始 1120×760 逻辑像素，按工作区限制。标题32/44、普通标题24/32、模式16/24、正文14/22；侧栏184、导航40高、按钮36高。固定字阶，选中不改变位置与字号。页面收缩和滚动，不整页缩放。

布局流程覆盖1440×1024、1280×800、1120×760和960×640；截图为测试输出，不是静态断言的黄金基线。生产构建须在停止 Vite 后独立检查本地字体、图标、路由、原生命令和 DEV 页面排除。

## 最近组合验收

2026-10-04 的组合候选完成24项前端测试、14项常规Rust测试、9项浏览器流程、12项原生生命周期步骤，以及词典真实磁盘重启和普通无安装包构建检查。精确提交、独立评审及完整日志由本机 Integration 记录关联。

实机覆盖 Windows 150% 缩放。100%/125%、多显示器、极小工作区、安装/卸载/签名、断电和系统崩溃注入仍未验证。原生菜单共用处理器检查不能替代实体鼠标路径；浏览器内存模拟不能替代磁盘持久化。

真实识别、模型、密钥、跨应用输入和完整业务页面不属于骨架验收。词典与交互动效的专项方法见 [数据验证](local-data-verification.md)、[动效验证](motion-verification.md)。
