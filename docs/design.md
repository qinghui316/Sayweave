# 视觉系统

当前实现采用浅色桌面布局。参数来源为 [tokens.css](../src/design/tokens.css)，组件覆盖值以对应 CSS 为准。

## 色彩与表面

| 基色 | 用途 |
|---|---|
| #FFFFFF | 内容面板与设置弹窗的主体表面 |
| #F6F6F6 | 主窗口、浅色控件及反白文字 |
| #CBCBCB | 辅助表面，通过透明度分层 |
| #000000 | 正文、数字、主要操作、选中导航和语音外壳 |
| #75FB91 | 图标、波形、确认反馈与首页局部材质 |

灰色填充：侧栏24%、快捷键48%、工作区38%、悬停18%，叠加在对应浅色表面上。辅助文字为黑色64%；弹窗遮罩为黑色28%。这些是填充透明度，不再叠加整对象透明度。

白色占主体。文字和数字不使用绿色；选中导航为黑底、浅色文字、绿色图标。层级主要依靠留白、表面与字阶，避免大面积灰卡和默认装饰分隔线。三种模式同级；导航选中不改变几何。

## 字体与比例

中文为 Noto Sans SC，品牌为 Inter，均随依赖打包。字号/行高如下（逻辑像素）：

| 用途 | 字号/行高 |
|---|---|
| 首页标题 | 32/44 |
| 功能页标题 | 24/32 |
| 模式与小节标题 | 16/24 |
| 正文与按钮 | 14/22 |
| 小字 | 13/20 |
| 元信息 | 12/18 |
| 首页用量数字 | 40/52 |

初始窗口1120×760，按工作区约束；不是按大型画布整体缩放。侧栏184、导航152×40、导航图标18、模式行64、图标20、快捷键148×36。窗口缩小时内容按布局收缩或滚动。

主窗口外沿、圆角与阴影由 Windows 管理。主窗口为不透明 #F6F6F6，页面外壳为矩形；html、body、根容器与侧栏/内容填满窗口内部。最大化与还原不改变页面填充。悬浮语音窗独立采用透明背景，不继承主窗口规则。

设置面板/卡片/控件圆角依次24/16/12；胶囊为999。基础间距使用 tokens 中的2–48px阶梯。

设置面板最大920×620，随视口留出边距；主窗口最小960×640。设置标题24/32、正文14/22、辅助13/20、常规输入与按钮36px。模型面板标题和类别页签固定；短表单操作区紧跟字段，长表单只在一个可收缩内容区滚动并保持操作可见。类别页签采用浅灰底座、白色选中块、局部绿色圆点和中性文字，200ms transform移动、120ms opacity淡入；减少动态时直接切换。名称与语音服务地址逐步展开。确认弹窗居中且显示标题与操作，焦点进入并在取消后恢复。导航悬停和选中用不同明度，几何保持不变。

## 局部材质与可访问性

历史采用连续白色列表，日期分组、固定时间列和右侧操作区。正文14/22、时间和辅助状态12/18，行高至少56px；摘要最多两行，完整内容在行下展开。操作区域预留宽度，悬停或聚焦不会挤动正文。日期按本地时间，行内时间为24小时制。标题和搜索固定，记录列表只有一个主滚动区；保存设置按需展开。菜单使用 Radix 焦点管理、边界避让和键盘操作；行内取消恢复“更多操作”焦点。所有变化仍保留可见焦点和减少动态支持。

用量材质叠加：浅白82%承托、绿色26%→40%、白色高光24%→6%→0%。阴影为黑色7%，0/5/16px；弹窗阴影黑色20%，0/16/48px。玻璃只用于特定表面，不扩展到全部功能面板。

36px 输入框给 22px 文字行保留完整内部高度；焦点轮廓绘制在控件内部，避免固定内容区裁切。搜索输入在弹性行中允许收缩，数量及操作保留自身空间。

焦点须可见。状态通过文字、图标与操作共同表达，不能只靠颜色。减少动态和窗口隐藏策略见 [动效说明](motion.md)。当前 Windows 150% 下，960×640 最小窗口尺寸由原生验收验证，设置布局另有浏览器与桌面检查。其他 DPI、多显示器、不同桌面背景下的外沿对照与材质表现仍需各自验证。


公共下拉、radio和开关使用同一受控动效边界，控件占位与文字不形变；交互参数和减少动态规则见 [motion.md](motion.md)。历史使用每页最多20条的稳定阅读分页，后台新增与删除不挤动当前页，详见 [history.md](history.md)。真实波形增加时间片能量及细微同色渐变，紧凑悬浮控件比例保持不变。
