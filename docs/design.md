# 视觉系统

当前实现采用浅色桌面布局。参数来源为 [tokens.css](../src/design/tokens.css)，组件覆盖值以对应 CSS 为准。

## 色彩与表面

| 基色 | 用途 |
|---|---|
| #FFFFFF | 内容面板与设置弹窗的主体表面 |
| #F6F6F6 | 主窗口、浅色控件及反白文字 |
| #CBCBCB | 辅助表面，通过透明度分层 |
| #000000 | 正文、数字、主要操作、选中导航和语音外壳 |
| #75FB91 | 图标、波形、确认反馈与首页局部材质 |

灰色填充：侧栏24%、快捷键48%、工作区38%、悬停18%，叠加在对应浅色表面上。辅助文字为黑色64%；弹窗遮罩为黑色28%。这些是填充透明度，不再叠加整对象透明度。

白色占主体。文字和数字不使用绿色；选中导航为黑底、浅色文字、绿色图标。层级主要依靠留白、表面与字阶，避免大面积灰卡和默认装饰分隔线。三种模式同级；导航选中不改变几何。

## 字体与比例

中文为 Noto Sans SC，品牌为 Inter，均随依赖打包。字号/行高如下（逻辑像素）：

| 用途 | 字号/行高 |
|---|---|
| 首页标题 | 32/44 |
| 功能页标题 | 24/32 |
| 模式与小节标题 | 16/24 |
| 正文与按钮 | 14/22 |
| 小字 | 13/20 |
| 元信息 | 12/18 |
| 首页用量数字 | 40/52 |

初始窗口1120×760，按工作区约束；不是按大型画布整体缩放。侧栏184、导航152×40、导航图标18、模式行64、图标20、快捷键148×36。窗口缩小时内容按布局收缩或滚动。

窗口/面板/卡片/控件圆角依次20/24/16/12；胶囊为999。基础间距使用 tokens 中的2–48px阶梯。

## 局部材质与可访问性

用量材质叠加：浅白82%承托、绿色26%→40%、白色高光24%→6%→0%。阴影为黑色7%，0/5/16px；弹窗阴影黑色20%，0/16/48px。玻璃只用于特定表面，不扩展到全部功能面板。

焦点须可见。状态通过文字、图标与操作共同表达，不能只靠颜色。减少动态和窗口隐藏策略见 [动效说明](motion.md)。其他 DPI、最小窗口、多显示器与材质表现仍需要各自实机验证。
