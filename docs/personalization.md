# 应用感知资料与后台学习

状态：当前开发分支的候选实现。已完成注册组件的隔离编辑与模型学习闭环，日常程序验收仍在进行。

口述继续由 Session／Turn／Draft 管理。语言资料只提供冻结快照，不拥有输入范围，不改写输入框，也不控制录音或窗口的结束。

## 资料流转

```text
捕获目标 → 原生应用身份 → 冻结词典、场景、偏好和设置
                         ├→ ASR 热词
                         └→ 当前整理提示词

实际输出收据 → 自有范围编辑证据 → 后台分类 → 正确词／歧义候选／表达观察
原始识别记录引用 ────────────────────────────→ 表达观察
按应用的新观察＋旧资料及支持证据 → 整体候选 → 版本校验发布 → 下一次口述
```

`contracts/language.rs` 保存中立契约；`windows_input/application.rs` 解析捕获进程身份；`language_policy.rs` 发布独立学习资格；`language_learning.rs` 管理后台调度与模型分析；`data/repositories/language.rs` 管理去重、抑制、事务和资料版本；`processing/prompt.rs` 选择并拼接资料。原生范围及其监听留在 text-service。

系统包身份优先，普通程序使用规范化可执行路径。PID、窗口句柄和启动时间只复核本次目标。浏览器统一使用 Web 范围，不读取域名、URL 或标题。安装路径改变的普通程序没有自动身份迁移；身份不可取得时仍可正常口述。

基础场景与个人习惯分开；偏好带应用范围、书写特征、适用语境及每条规则的来源。书写特征是 Han、Latin、Mixed、Other，不能当作精确语种识别。共享规则逐条核验跨应用来源。当前会话不随后台发布改变资料。

## 提示词与热词

faithful-v2 保留原模板，只补语气、句式顺序、术语、数字和场景边界。明确自我纠正优先于保留过渡语和旧说法。正文请求不执行；词典、场景和偏好只是受限参考。普通整理正文不经过学习模块的语义分类。

术语和已有纠错映射继续分开。自动学习只新增正确词形；手动维护优先，自动词条可随新的明确纠正更新大小写。删除抑制阻止迟到结果加回。

Qwen Streaming 使用 `parameters.vocabulary`，初版权重4；豆包使用字符串化的 `request.corpus.context`。单次最多100个词，并有保守的8KiB序列化预算；不限制词典存量、不截断词形。热词是识别倾向，不是强制替换。单词库按最近维护顺序选择；语境检索属于后续选择策略。

## 观察与后台生命周期

写入协议仍为8，独立协商只读观察能力2。能力缺失或观察失败不阻断正常口述。证据绑定任务、轮次、操作、prefix／tail、修订和实际范围；前端不能指定外部范围。

观察最多60秒，停键15秒结算；未结束的 IME 不发布。正文只读自有范围，编辑证据十分钟内过期，分类完成或确定失败后清除暂存正文。普通 EDIT 使用已验证的原生坐标和编辑消息；其他字段使用原生焦点窗口、UIA fragment 与 element RuntimeId，并保留原字段 provider 复核焦点。COM 包装对象地址和正文相同均不能证明字段相同。富文本 GROUPING 还需明确可写的 TextPattern 属性；未知属性、只读或密码状态结束观察。自身写入、范围外修改、旧轮次和重复通知不作为新纠正。

标准 EDIT 撤销消息和物理撤销／重做按键可撤销观察；已知原选区恢复只作否定学习检查。它不证明所有宿主的菜单、脚本或格式撤销，也会保守排除主动改回原选区。未知原文不补读或猜测。注册组件已覆盖 RichEdit、浏览器 input、textarea、contenteditable 和 ProseMirror 的实际更正、等正文双字段隔离，以及注入删除键交接。受控 IME 证据不能代替日常输入法验收；可选观察挂接完成前的极快编辑可能无法形成可靠证据。

可选观察超时后，仅丢弃该操作已知身份的迟到回执，核心写入的未知错配仍拒绝；待弃置身份有固定上限，耗尽时停止可选工作。字段切为只读或密码后停止新增范围读取，原键盘消息仍交给控件。

后台复用默认文字模型、共享请求协调及一个 DataWorker，最多一笔模型分析在途。口述抢占会取消配置读取与生成；真实纠正保留同一证据身份，在原期限内恢复。网络、认证及结构错误不无限重复生成。资料分析失败保留上一版，没有新证据不重复调用；每个范围至少间隔十分钟，前台抢占可恢复未完成工作。

每应用累计10次新口述观察，或至少3个独立会话的3次表达修改，在空闲30秒后分析。这些数值是派发条件，不代表偏好一定成立。旧支持和新样本共用提示预算，节选标记不完整，不把缺失当反证。无变化也结算观察水位。

自动入词与个性化分别保存开关和修订。编辑观察和分类共用，冻结两份资格；关闭其中一项只撤销本项资格，原始证据仍为另一项保留。分类结果在事务中按本项当前修订分别结算；关闭再开启不重新授权旧观察或回包。个性化关闭时不采集表达观察、不提炼新偏好，下一次口述不加入场景或偏好；自动入词继续运行。自动入词关闭时不生成词条或歧义候选，个性化仍可运行。已有词典始终可用于 ASR 和整理，整理口述开关不控制后台学习。当前口述仍使用冻结的场景、词典和偏好。

只读监听与写入监听共用目标线程的通知深度及精确 context／cookie 退役队列；通知中立即撤销权限，在通知外取消订阅。结束后释放写入侧空租约，保留只读观察；原生已经验证的提交后范围用于挂接收据，不重复提交文字。关闭、重新激活和卸载按各自资源身份清理。

独立维护任务清理过期正文，退出纳入现有五秒协调。原始识别复用新任务历史引用；不回溯上传全部历史，不保存额外的外部全文。无持久识别引用时，仍可使用有效的短时编辑证据。
