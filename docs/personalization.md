# 应用感知资料与后台学习

学习与资料契约保持 schema10、TSF 写协议10和观察协议2。当前页面只读呈现已发布资料；实际环境的覆盖范围以对应验收记录为准。

口述继续由 Session／Turn／Draft 管理。语言资料只提供冻结快照，不拥有输入范围，不改写输入框，也不控制录音或窗口的结束。

## 资料流转

```text
捕获目标 → 原生应用身份 → 冻结词典、场景、偏好和设置
                         ├→ ASR 热词
                         └→ 当前整理提示词

实际输出收据 → 自有范围／原输入框快照纠错证据 → 后台分类 → 正确词／歧义候选／表达观察
原始识别记录引用 ────────────────────────────→ 表达观察
按应用的新观察＋旧资料及支持证据 → 整体候选 → 版本校验发布 → 下一次口述
```

`contracts/language.rs` 保存中立契约；`windows_input/application.rs` 解析捕获进程身份；`language_policy.rs` 发布独立学习资格；`language_learning.rs` 管理后台调度与模型分析；`data/repositories/language.rs` 管理去重、抑制、事务和资料版本；`processing/prompt.rs` 选择并拼接资料。原生范围及其监听留在 text-service。

系统包身份优先，普通程序使用规范化可执行路径。PID、窗口句柄和启动时间只复核本次目标。浏览器统一使用 Web 范围，不读取域名、URL 或标题。安装路径改变的普通程序没有自动身份迁移；身份不可取得时仍可正常口述。

基础场景与个人习惯分开；偏好带应用范围、书写特征、适用语境及每条规则的来源。书写特征是 Han、Latin、Mixed、Other，不能当作精确语种识别。共享规则逐条核验跨应用来源。当前会话不随后台发布改变资料。

## 提示词与热词

faithful-v2 保留原模板，只补语气、句式顺序、术语、数字和场景边界。明确自我纠正优先于保留过渡语和旧说法。正文请求不执行；词典、场景和偏好只是受限参考。普通整理正文不经过学习模块的语义分类。

自动学习只新增正确词形；手动维护优先，自动词条可随新的明确纠正更新大小写。删除抑制阻止迟到结果加回。

Qwen Streaming 使用 `parameters.vocabulary`，初版权重4；豆包使用字符串化的 `request.corpus.context`。单次最多100个词，并有保守的8KiB序列化预算；不限制词典存量、不截断词形。热词是识别倾向，不是强制替换。单词库按最近维护顺序选择；语境检索属于后续选择策略。

## 观察与后台生命周期

写入协议为10，独立协商只读观察能力2。能力缺失或观察失败不阻断正常口述。证据绑定任务、轮次、操作、prefix／tail、修订和实际范围；前端不能指定外部范围。

观察最多60秒，实际修改稳定15秒后结算；焦点离开或新的自有写入结束上一观察边界时，可提前结算已经核实的纠错缓存。原字段暂时为空时，在同一期限内保留交付基线，以覆盖逐字删除后重打；块外前后文仍须匹配。原范围观察沿用其原生组词判断；输入框快照按稳定变化结算，UIA 组合范围只作诊断。编辑证据十分钟内过期，分类完成或确定失败后清除暂存正文。原范围观察使用自有连续范围；普通 EDIT 使用已验证的原生坐标和编辑消息，其他字段使用原生焦点窗口、UIA fragment 与 element RuntimeId，并保留原字段 provider 复核焦点。COM 包装对象地址和正文相同均不能证明字段相同。富文本 GROUPING 还需明确可写的 TextPattern 属性；未知属性、只读或密码状态结束观察。自身写入、范围外修改、旧轮次和重复通知不作为新纠正。

原输入框快照作为独立的只读证据来源，由一个后台 MTA 执行器读取原控件的 TextPattern／TextPattern2 或明确可写的 ValuePattern。原应用、实际编辑端点、控件及文本容器关系均需核实；原窗口内换框同样结束这项观察。读取上限64KiB，完整字段仅留在内存中，只有实际交付文字的唯一对应范围及其纠错片段可进入既有分类和存储。重复文本、范围外变化、读取不完整或来源无法核实时不生成证据。原范围和快照描述的同一次纠错使用同一身份，沿用仓储幂等处理。

快照常规轮询间隔1秒，键盘变化合并等待100ms；同时只有一笔UIA读取。写入前发布来源栅栏，真实交付后更新基线；读取返回时再次核对来源代次与资格。慢调用和迟到答复不能阻塞输入，也不能把模型自身改写算成用户纠错。快照不操作焦点、选区或剪贴板，不授予输入许可。

学习范围可以包含同一原输入框内唯一、不重叠且相邻的多个自有交付片段，避免原生块切换把一个词的逐字删改拆开；私有间隙和重复匹配不拼接。原生证据只有在完整快照纠错实际结算、且能唯一对应其片段时才去重。待结算原生记录最多16笔，17秒本地期限不依赖UIA返回；失败或退出观察释放未匹配记录。下一轮开始时，可直接结算已捕获的归属有效纠错，不等待新的UIA读取。有未处理输入活动时不发布旧缓存；原字段暂时为空仍受原有观察总期限约束。

标准 EDIT 撤销消息和物理撤销／重做按键可撤销观察；已知原选区恢复只作否定学习检查。它不证明所有宿主的菜单、脚本或格式撤销，也会保守排除主动改回原选区。未知原文不补读或猜测。注册组件已覆盖 RichEdit、浏览器 input、textarea、contenteditable 和 ProseMirror 的实际更正、等正文双字段隔离，以及注入删除键交接。受控 IME 证据不能代替日常输入法验收；可选观察挂接完成前的极快编辑可能无法形成可靠证据。

可选观察超时后，仅丢弃该操作已知身份的迟到回执，核心写入的未知错配仍拒绝；待弃置身份有固定上限，耗尽时停止可选工作。字段切为只读或密码后停止新增范围读取，原键盘消息仍交给控件。

后台复用默认文字模型、共享请求协调及一个 DataWorker，最多一笔模型分析在途。口述抢占会取消配置读取与生成；真实纠正保留同一证据身份，在原期限内恢复。网络、认证及结构错误不无限重复生成。资料分析失败保留上一版，没有新证据不重复调用；每个范围至少间隔十分钟，前台抢占可恢复未完成工作。

每应用累计10次新口述观察，或至少3个独立会话的3次表达修改，在空闲30秒后分析。这些数值是派发条件，不代表偏好一定成立。旧支持和新样本共用提示预算，节选标记不完整，不把缺失当反证。无变化也结算观察水位。

自动入词与个性化分别保存开关和修订。编辑观察和分类共用，冻结两份资格；关闭其中一项只撤销本项资格，原始证据仍为另一项保留。分类结果在事务中按本项当前修订分别结算；关闭再开启不重新授权旧观察或回包。个性化关闭时不采集表达观察、不提炼新偏好，下一次口述不加入场景或偏好；自动入词继续运行。自动入词关闭时不生成词条或歧义候选，个性化仍可运行。已有词典始终可用于 ASR 和整理，整理口述开关不控制后台学习。当前口述仍使用冻结的场景、词典和偏好。

只读监听与写入监听共用目标线程的通知深度及精确 context／cookie 退役队列；通知中立即撤销权限，在通知外取消订阅。正常结束先交还组合并释放块，再转移只读观察租约；不重复提交文字。编辑接管取得有效范围后重新挂接观察，分段交付分别携带实际来源。强制关闭仍等待实际 Retirement，新一轮开始前结算并退役旧观察。关闭、重新激活和卸载按各自资源身份清理。

独立维护任务清理过期正文，退出纳入现有五秒协调。原始识别复用新任务历史引用；不回溯上传全部历史，不保存额外的外部全文。无持久识别引用时，仍可使用有效的短时编辑证据。

001—008保持冻结。009 增加自动入词的独立设置及编辑资格／结算状态，自动入词默认开启，原开关状态保留为个性化。旧格式待分类编辑失效且不重放；已有词条、抑制、候选和偏好保留。资料、候选、来源、模型和模板版本可追踪；已生效版本不原地覆盖。首版不提供偏好编辑或逐应用设置界面。

## 设置入口与即时保存

主导航的「个性化」进入独立 `/preferences` 页面，管理表达学习与应用风格。设置弹窗没有重复页签；旧路径继续有效。「词典」页顶部管理自动入词，保留所有、自动添加和手动添加筛选。模型的「文字处理」只保留整理口述开关。

功能开关点击即保存，关闭、切页不弹未保存确认。主窗口持有有界保存投影，同一功能串行并合并最新意图，页面卸载不取消已发送请求；按独立修订结算。保存答复丢失时只读核对实际值，不重复写入。麦克风与历史保留共用录音偏好并保留其他字段。后台学习资格与会话冻结规则不因入口调整而改变。

## 词典与个性化数据面板

词典默认展示正确词语，所有／自动添加／手动添加共用紧凑筛选。搜索从圆形按钮展开，非空查询保持可见，Esc 清空并收起。纠错映射已停用，旧记录仅保留存储兼容，不进入词典界面、识别热词或文字模型上下文。词语编辑默认只有词形，补充设置维护已有分类。

个性化面板只读显示当前已发布的规则、已记录应用及有效学习记录。共享规则仅计一次，候选、旧版本和基础场景不算已学习惯；词典词条不计入表达统计。来源为保存时的应用身份，不查询当前前台，也不返回口述正文、证据引用或模型分析。应用分页20项，详情按范围与版本结算。关闭个性化仍可阅读已保存资料；看板读取不会触发模型调用，失败不影响设置保存。

快照学习依据原字段的最近修改、稳定时间和生命周期边界结算。UIA 可能在提交后仍返回组合范围，因此该元数据不作为采集或分类门槛，稳定的预编辑文字也可能成为分类候选。读取竞态暂停结算并保留内存快照；新快照更新或撤销候选。结算前的取消、撤销和恢复原文不产生相应词条，纯删除仍按既有分类抑制处理。输入法组合的写入保护由原生输入独立拥有。

已捕获的纠词可以在输入框提交清空或焦点离开时提前结算。只读观察记录最近的物理编辑与提交／点击边界；中间存在尚未读到的其他输入时，不使用旧缓存。空字段的布局换行只用于判断边界，结算内容仍是此前核实的纠词片段。单片段与连续片段都登记实际交付身份；相同正文的不同操作不能被当成重复收据。字段结算后，该覆盖范围的旧原生收尾结果不再构成另一份纠词。普通删除后重打仍保留原基线，组词、录音及正文写入不依赖这项观察标记。
