# 口述翻译（开发候选）

本功能尚未合入正式版。普通口述继续实时输入；翻译共用录音与本地／云端识别，结束后调用当前文字模型并一次性交付。默认普通键右 Alt，翻译键右 Alt＋右 Shift，点按在松开时确定完整手势，不提前启动其前缀。纯修饰键组合仅支持点按；按住模式可设置独立单键或普通组合键。不能启用的配置在键位框内提示并保留原设置；两个用途共用系统保留键校验，无法枚举所有第三方程序的快捷键。

录音期间外部正文不变，不创建连续 Draft、不调用分段整理、不建立原语言纠词观察。翻译不受普通整理开关影响，缺少文字模型在录音前提示。普通任务和翻译任务使用同一个准入所有者。

语言目录及提示词名称由 `contracts/translation.rs` 维护。设置允许添加全部受支持语言，保留至少一种；不提供手动排序，新增语言追加到末尾，记住上次选择。录音中按任务身份选择；结束与选择在同一锁下结算，结束后目标冻结。菜单复用现有主题、高亮和非激活窗口，点击外部关闭。浏览器适配仅用于界面模拟。

最终识别全文作为数据传入专用翻译提示词，只执行一次完整翻译请求；口述中的指令不改变系统用途。模型配置、密钥及词典按任务冻结。生成期间取消撤销发布资格，旧结果不能写入新任务。

开始时保留原字段、正文与选区的只读证明。交付前消费这份证明，再独立经过既有原生 Begin、更新和提交核验；临时证明本身不授予写权。目标变化或写入效果不确定时不重试，结果保留供复制。失败原文不会自动冒充译文填入。

schema12在原库增加翻译偏好、单键配置及历史用途／目标元数据；旧记录解释为普通口述。开发验证只升级独立资料。TSF核心、代理、本地推理协议及权重不变。真实宿主与麦克风试用独立结算，既有Tab编辑接管限制不属于本次修复。

试用反馈修正：默认常用语言为英语（美国）、日语、韩语、法语、中文（简体），其他语言仍在设置中添加或替换。schema13只更新未配置过的旧默认项，保留自定义配置；不修改已应用的schema12迁移。翻译录音/处理期间固定透明画布，语言菜单不触发窗口缩放与重定位。

启用右 Alt＋右 Shift 时，快捷键所有者保留右 Alt 前缀：配置了单独右 Alt 用途时，单键松开启动该用途；未配置时，单独松开不启动任务。翻译操作为先按 Alt 再加 Shift，或两键一起按；任意一键先松开都只结算一次。AltGr 继续按原保护处理。

设置页录入期间暂时暂停应用已注册的快捷键，避免原绑定抢走录入按键；完成或取消后恢复。当前页面与原生录入结果由同一 token／代次所有者结算一次，迟到结果不能覆盖新的录入。候选仍经原保存校验，保留键或冲突项显示行内错误，原设置不变。
