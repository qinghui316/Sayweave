# 源码分发规则

仓库分发应用源码、配置、锁文件、测试源码、可复现检查、当前设计参数及必要第三方许可。

不跟踪用户数据库、密钥、录音、`.local/`工具与运行状态、依赖、构建、截图/性能报告、冻结Figma大文件、参考仓库或本机Harness执行记录。测试产物保存在忽略目录，验收日志由本机资料关联。

上传前检查`git ls-files`，同时审查所有拟发布分支及其历史。`.gitignore`不会自动删除已跟踪文件，也不会清除旧提交。发现秘密时必须先撤销凭据，再处理历史；删除仓库不能撤销凭据。

当前仓库私有。开放源码前需确定项目自身许可，复查所有可达历史、外部设计资料与品牌分发权，并形成明确的公开版本。第三方许可不等于项目自身已选择开源许可；现阶段不宣称可公开分发或已正式发布。

本机Harness单独管理。新机器仅运行应用不依赖Harness；Agent工作流需要按AGENTS.md安装匹配项目ID的Skill。
