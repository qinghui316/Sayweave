# 设计资料入口

[DESIGN.md](../DESIGN.md) 保存当前视觉规则、配色、透明度、字体、桌面尺寸与历史画布差异；[组件对应](../docs/design-map.md) 将设计部位映射到源码；[动效说明](../docs/motion.md) 记录状态与窗口时序。

应用默认窗口为 1120×760 逻辑像素。1440×1024 为历史设计画布，不能直接当作运行尺寸。当前仅浅色基线，白色主体、浅灰辅助、黑色文字和绿色图形反馈。

本机另有日期冻结包 `design/exports/2026-10-03-v0.1/`，包含 Figma 本地副本、原尺寸预览、实际节点参数及差异清单；大文件、参考截图与探索稿不随源码仓库分发。它们是历史资料，不替代当前代码中的桌面适配。

品牌与图标源文件、字体与第三方许可见 `src/assets/`。仅有静态预览不能证明真实连接、下载或语音能力；应用中的试说仍为演示。
